# General: source order

Default for non-music research. Order: primaries -> records -> press -> scholarship -> wikis; a distributor-run wiki is a second source beside a primary.

- Microsoft / Azure / .NET: Microsoft Learn search API (`microsoft-learn.docs`) before web search.
- Library or SDK behaviour: a library-docs surface (or cloned source), never blog posts alone.
- Papers: the scholarly-archive surfaces (routing.md) or Exa, then publisher page for citation URL.
- Registries and API dumps (ClinicalTrials.gov, PubMed search results, any `pageSize=` listing): use them as a source list. Fetch one record per relevant study, at most 5 per registry (agent rule, not enforced in code); never ingest the whole listing.
