# P1: axes

Contract: gates, CLI and the state machine are in ../SKILL.md. This playbook is the detail for this phase.

## P1: axes

Record one axis per independently succeeding outcome: `axis --label <short name>`. `G_AX` requires at least one axis, unique ids, a non-empty label on each, and every active fact's `axis` to name an existing axis.

Launch one read-only lane per axis in parallel, in one turn; keep working while they read. Each lane prompt carries TASK / DELIVERABLE / SCOPE / VERIFY and its role. A subagent's summary is a claim until the exact file or command confirms it; record only the confirmed fact in P2.

Then go to P2 evidence (`phases/02-evidence.md`). Axes are inputs to evidence, not a plan deliverable.
