# Classical: source order

1. Grove / Oxford reference: composer dates, era, output.
2. Publishers (Universal, Bärenreiter, Schott, Eschig): scoring, catalog scope.
3. Orchestra program notes (LSO, Berlin Phil, Concertgebouw, LA Phil): context.
4. Deep-catalog labels: Chandos, Hyperion, BIS, Naxos, CPO, Capriccio.
5. Release/discography lookups: skill `music-lookup-artists` `references/routing.md` (method: `../rules.md` "Discography").

Sources conflict on dates: prefer catalog entry; state conflict in one line.
